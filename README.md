# Real-Time E-Commerce Data Engineering and Analytics Pipeline

## Project Overview

An end-to-end data engineering project that collects,
processes, stores, and analyzes e-commerce data in real time.

## Technology Stack

- Python
- PostgreSQL
- Apache Kafka
- Apache Spark
- Apache Airflow
- Docker
- Power BI

## Project Goals

- Build a real-time data pipeline
- Process e-commerce events
- Store structured data
- Perform data transformation
- Build a data warehouse
- Automate data pipelines
- Create analytics dashboards
